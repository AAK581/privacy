# Privacy policies for Doma's games

Published with GitHub Pages: https://aak581.github.io/privacy/

## Adding a game

1. Make a folder named after the game, e.g. `engineering-marvels-from-hell/`.
2. Copy `_template-with-ads.md` into it as `index.md` (that template covers a
   game with AdMob ads and/or a Google Play in-app purchase). For a game with
   no ads and no purchases, delete the "Data collected by Google" section and
   say so instead - the policy must match what the game actually does, because
   Google cross-checks it against the Play Console Data safety form.
3. Replace GAME NAME and DATE.
4. Add a link to it in `index.md`.
5. Add the game's name to the list at the top of `terms/index.md`, and update
   the date there.
6. Commit and push. The page appears at
   https://aak581.github.io/privacy/<folder-name>/

## Terms of Service

One shared page covers every game: https://aak581.github.io/privacy/terms/
It names each game, because Google Play wants terms that apply to the app.
